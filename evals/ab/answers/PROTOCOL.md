# Answers protocol: who reads what

- Task authors: the repo and its `<repo>.md` only. For clinic, `clinic.md` distils the spec; the spec itself is not given.
- Setup operator (answers the docs tool's popups): `<repo>-operator.md` and `<repo>.md`.
- Trial agents: only their trial copy, which carries `<repo>.md` as `BUSINESS-NOTES.md` in every arm, A0 included.
- Provenance files, operator files and this protocol are never copied into a trial.
